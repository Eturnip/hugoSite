这个站点使用 Hugo 和 Stack 主题来生成内容。若要新增内容，可以在 content/post 目录下添加 Markdown 文件，并在前言中设置 title、date 与可选的 categories/tags。

## 目录结构

- content/post：文章内容
- content/about：关于页
- config/_default：主题与站点配置
- static：静态资源

## 发布方式

在本地可以运行 hugo server 预览，随后生成静态站点并部署到静态托管服务。
